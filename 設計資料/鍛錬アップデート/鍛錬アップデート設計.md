# 鍛錬アップデート設計

## 1. 目的

既存の「鍛錬」コマンドを拡張し、オートバトルで使用する能力値も育成できるようにする。

鍛錬に使う時間と、どの能力を伸ばすかをプレイヤーが選べるようにする。まずは単純な育成機能を実装し、他の行動や育成手段が増えた段階で効率・バランスを調整できる余地を残す。

## 2. 現状

- 鍛錬は既存コマンドとして実装されている。
- 鍛錬1回の消費時間は **3時間固定**。
- 育成対象は現在、労働効率のみ。
- オートバトル自体は実装済み。

## 3. 今回の実装方針

### 3.1 育成対象

既存の労働効率に加え、以下の戦闘能力を鍛錬可能にする。

| 能力値 | 主な用途 |
| --- | --- |
| 労働効率 | 労働収入を増やす |
| 攻撃力 | 戦闘で与えるダメージを増やす |
| 防御力 | 戦闘で受けるダメージを減らす |
| タフさ | 戦闘中の最大HPに関わる |
| 素早さ | 行動ゲージの蓄積速度を上げ、攻撃頻度を増やす |

- **5能力すべてを鍛錬で上げられる**ようにする。
- 能力ごとの具体的な上昇量・初期値は、既存実装を確認した上で別途決定する。
- 鍛錬以外の育成手段は今回実装せず、後日必要に応じて検討する。

### 3.2 操作の流れ

1. メイン画面の既存「鍛錬」コマンドを選択する。
2. 鍛錬専用ダイアログを開く。
3. 育成する能力を1種類選択する。
4. 鍛錬時間を指定する。
5. 消費資源と能力値の変化を確認する。
6. 実行すると、指定した鍛錬を行ってダイアログを閉じる（終了後の表示動作は既存画面との整合を見て調整可）。

### 3.3 ダイアログの構成

- **ヘッダー**：タイトル「鍛錬」と閉じる操作。
- **能力選択欄**：5能力の名称・現在値・簡潔な効果説明・鍛錬後の予想値を表示する。選択中の能力を明示する。
- **時間指定欄**：鍛錬に使う時間を選択する。選択可能な最小単位・上限・入力UIは未確定。残り時間を超える指定は実行できないようにする。
- **実行内容の確認欄**：選択能力、成長量、消費時間、その他の既存消費資源（HPなど、実装されている場合）を表示する。
- **操作欄**：実行・キャンセル。

メイン画面の鍛錬カード自体は大きく変更せず、詳細な選択操作をダイアログ内にまとめる。

## 4. 鍛錬時間と成長効率

### 4.1 初期方針

- 現行の「3時間固定」から、**鍛錬時間を選択できる形式**へ変更する方向とする。
- 初期実装では、**成長量は鍛錬時間に比例**する単純な方式を基本とする。
- 短時間の鍛錬も選べることで、1日の残り時間を活用しやすくする。
- 長時間鍛錬の効率ボーナスは、**今回は導入しない**。

### 4.2 将来の調整余地

長時間鍛錬ほど成長効率が上がる仕組みは、将来の調整候補とする。

- ボーナスの有無や倍率・適用条件を、後から変更しやすい設計を意識する。
- ただし、未使用の複雑な成長ポイント制度やボーナス計算を先行実装する必要はない。
- 時間とHPの使い道がまだ少ない現状では、長時間ボーナスが「まとめて鍛えるのが常に正解」という選択になりやすい。
- 探索・製作など他の時間消費行動が増えた場合、長時間鍛錬と他の行動とのトレードオフが生まれる可能性がある。
- 同じ合計時間を分割して鍛錬した場合と一度にまとめた場合の扱いは、ボーナス導入時に検討する。

## 5. バランス調整の考え方

- 労働効率の強化は収入を増やす投資、戦闘能力の強化は危険な労働への対応力を高める投資として位置づける。
- 育成対象の選択自体が、時間という共通資源を巡る判断になる。
- 能力ごとに成長量を変えられるようにする。全能力を同じ数値だけ上昇させる必要はない。
- 育成コストは、現行方式を基本とし、能力値が高いほど高コストになる仕組みは現段階では導入しない方針。
- 実際のプレイで強すぎる能力・弱すぎる能力が判明したら調整する。

## 6. 今回の対象外

- ショップやアイテムなど、鍛錬以外の育成手段。
- 装備による能力補正の実装。
- 長時間鍛錬ボーナスの実装。
- 新しい時間消費行動の追加。
- 戦闘ルールそのものの変更。

将来、基礎能力値と装備等による補正値を分けて扱えると拡張しやすいが、今回その仕組みを必須とはしない。

## 7. 実装前に確認・決定する事項

1. 鍛錬時間の選択単位・最小値・最大値（例：1時間単位など）。
2. 各能力の時間あたり成長量と、端数処理の方法。
3. 既存の鍛錬が消費するHP等の資源と、時間可変化に伴う消費量の計算。
4. 1日の残り時間が少ない場合の入力制限と実行可否。
5. 既存の鍛錬処理・能力値管理と新しいダイアログの接続方法。
6. 鍛錬後のダイアログの閉じ方や結果通知方法。

## 8. 実装完了の目安

- 鍛錬ボタンから専用ダイアログを開ける。
- 5能力の中から育成対象を選べる。
- 指定可能な範囲で鍛錬時間を選べる。
- 実行前に成長量と消費資源を確認できる。
- 実行後、選択した能力が正しく上昇し、時間などの資源が正しく減少する。
- 戦闘能力の上昇が既存オートバトルに反映される。
- 長時間ボーナスがなくても成立し、将来の調整を妨げない。

---

**設計状態**：方向性は合意済み。数値・時間選択範囲・端数処理などは未確定。実装前に決めるか、仮値を明示して進める。
