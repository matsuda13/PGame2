# 状況変化イベント設計

## 1. 目的

一定周期でゲーム内の状況を変化させ、労働・休憩・鍛錬などの既存コマンドの価値を変える。イベント内容は事前に予告し、プレイヤーが準備・対応を選べるようにする。

## 2. 基本仕様

| 項目 | 仕様 |
| --- | --- |
| 発生周期 | 15日ごと |
| 継続期間 | 10日間 |
| 予告タイミング | イベント開始8日前 |
| 選出方式 | イベント候補からランダム選出 |
| 連続選出 | 直前と同じイベントは選出しない |
| 同時開催 | 最大1件 |
| 情報表示 | 開催中イベントと次回予告を同時に表示できる |
| 小目標との関係 | 小目標の20日周期とは独立して進行 |

### 周期の例

- 1〜10日目：イベント開催
- 8日目：次のイベントを抽選・予告（現在のイベント開催中）
- 11〜15日目：イベントのない期間。次回イベントは予告済み
- 16日目：次のイベント開始

※上記は初回イベントが1日目に始まると仮定した例。ゲーム開始後、最初のイベントをいつ開始するかは別途決定する。

## 3. イベント一覧

| イベント名 | 効果 | 分類 |
| --- | --- | --- |
| 酷暑 | 労働による体力消費 +30% | デメリット |
| 魔獣活発化 | 戦闘発生確率 +30pt | デメリット |
| 好景気 | 労働賃金 +20% | メリット |
| プロテインの雨 | 鍛錬による能力上昇量 +100%、鍛錬の体力消費 +100% | トレードオフ |
| 春眠暁を覚えず | 1日の使用可能時間 -1時間、休憩の所要時間 +2時間、毎日の開始時に体力全快 | ルール変更・トレードオフ |

### 効果範囲の注意

- 「酷暑」の体力消費補正は労働にのみ適用する。戦闘や鍛錬による体力減少には適用しない。
- 「プロテインの雨」の鍛錬効率 +100% は、鍛錬による能力上昇量が基本値の2倍になることを意味する。
- 「春眠暁を覚えず」の体力全快はイベント開催中の**毎日の開始時**に適用する（初日も含む）。日中の休憩は通常どおり利用できるが、所要時間が2時間増える。
- 休憩の所要時間がその日の残り時間を超える場合、休憩は実行できない。


## 5. 日付変更時の処理順序

1. 終了日を迎えた前イベントを終了する。
2. 当日開始予定の新イベントを開始する。
3. 当日開始時に発動するイベント効果を適用する（春眠の体力全快など）。
4. プレイヤーの行動を受け付ける。

※イベント予告の発行も該当日の開始時処理で行う想定。開催中イベントと次回予告は併存可能だが、イベント効果そのものは重複しない。

## 6. 実装上の留意事項

- イベントの選出時は直前のイベントを候補から除外する。
- 予告されたイベントは開始時に再抽選しない。
- イベントの補正は各コマンドの基本値を参照して適用し、効果終了後は通常の計算に戻す。
- 春眠による休憩時間増加には既存の残り時間不足判定を適用する。
- 小目標の20日周期とは独立させ、周期の位相が少しずつずれるようにする。
