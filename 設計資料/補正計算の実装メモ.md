# 補正の設定とパラメータ反映

基本値は Work.DEFAULT / Train.DEFAULT、イベント補正は SituationEvents.Kind で調整する。
イベントの数値説明は補正定義から生成するため、説明文の数値を別途書き換える必要はない。

```java
modifier(WORK_HP_COST, percent(30))       // 労働のHP消費 +30%
modifier(TRAIN_ABILITY_GAIN, percent(100)) // 鍛錬の獲得能力値 +100%
modifier(REST_HOURS_COST, fixed(2))       // 休息の消費時間 +2
modifier(BATTLE_CHANCE, points(30))      // 戦闘発生確率 +30pt
```

明示倍率は multiply(2) または multiply("1.5") で定義する。
割合補正を合算し基本値に適用 → 固定値/ptを合算して加算 → 明示倍率を乗算する。
複数の明示倍率は積として適用する。BigDecimalを使い、計算途中では丸めない。
割合の +100% は他の割合に加算するもので、明示倍率 ×2 とは異なる。

Effectsは小数を保持する。資源への反映は GameSession の changeHp / changePlun /
changeAbility / changeHours を通し、現在値と増減を合算した最終値を floor する。
HP100で消費15に+30%なら、floor(100 - 19.5) = 80。
HPの既存の0〜最大HP制限は維持し、他の資源や消費量に新しい下限を追加しない。
確率は最終値を切り捨てて0〜100に制限する。

カードは丸め前の補正済み効果を表示し、行動ログは最終値に反映された増減を表示する。
小目標報酬は従来どおり専用通知に分け、行動のプルン増減には含めない。
毎朝のHP全快と時間リセットは専用メソッドで行う。
複数の労働・鍛錬からの選択機能は今回追加していない。
